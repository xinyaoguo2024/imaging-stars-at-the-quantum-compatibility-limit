# Remote3 source morphology optimization

This diagnostic keeps the observing setup fixed at remote3, 36 x 10 min, SNR boost 1,
and 0.2 dB/km fiber loss.  It tests three modified AGN input morphologies with broader,
resolved tails and less sinusoidal BLR angular structure.  Each source variant gets an
independent RML prior-weight scan before all/edge/direct are compared.
